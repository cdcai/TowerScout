TowerScout V1 RC1

Project Overview

TowerScout is a local web application for identifying likely cooling towers from satellite and aerial imagery during investigation and registry-building workflows.

Sections

What The Package Provides

The V1 RC1 package provides a Windows-first local pilot path with a GitHub Release control ZIP, pinned GHCR image digest, Compose runtime configuration, CPU-safe default launch, optional Docker GPU controls, helper scripts, package-local docs, and release notices.

The normal pilot path is package-based. Source checkout, Python virtual environment, and Conda setup guides are legacy support material.

What Users Need Installed

Pilot users need Windows 11 AMD64, PowerShell, a modern browser, normal outbound internet access, and one approved container engine. The container engine can be Podman with a running Podman machine and Compose provider, or Docker Desktop where it is licensed and approved.

The package path does not require Git, Python, Conda, Node.js, VS Code, or a source-code checkout.

Main Workflow

  1. Start TowerScout from start.bat.
  2. Import required model and ZIP-code assets.
  3. Configure Google Maps or Azure Maps.
  4. Define a search area and estimate tiles.
  5. Run detection, review results, add manual corrections, and export approved outputs.

Release Boundary

V1 RC1 targets Windows 11 AMD64, single-user local use, CPU baseline operation, normal outbound internet access, a Docker-compatible or OCI-compatible runtime with Compose support, and one site/user-owned restricted provider key.

GPU launch is optional and Docker-first. The default launch remains CPU-safe. Podman GPU launch is not validated for V1 RC1.

Provider Keys

Browser map SDK keys are visible to someone with access to the running browser app. V1 RC1 expects site/user-owned restricted keys and does not support unrestricted shared TowerScout project keys.
