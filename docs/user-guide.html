Before Using This Guide

This guide assumes the package setup work is already complete: Docker Desktop is installed, approved, and running for the primary pilot path or support has explicitly directed you to a qualified Podman path; required assets are imported; TowerScout opens at http://localhost:5000; and at least one provider key is configured.

When this guide shows package commands, run them from Windows PowerShell opened in the extracted TowerScout package folder. Commands that begin with .\ run scripts from that folder.

If any of those are not true, start with the Quick Start.

Choose A Provider

TowerScout supports Google Maps and Azure Maps. One valid provider key is enough to start. If both are configured, use the provider selector for the current workflow.

Browser map SDK keys are client-visible. The package assumes site/user-owned restricted keys.

Define A Search Area

Search by address, city, neighborhood, ZIP code, or manual pan and zoom. Keep first searches small so tile counts and processing time stay manageable.

For custom search-area polygons, Azure Maps uses double-click to complete the polygon. Google Maps uses right-click outside to complete the polygon.

Estimate And Detect

Select Estimate tiles before Find towers. The estimate shows expected tile count and rough processing time. If the count is too large, clear the area or draw a smaller one before detecting.

Review Results

Results appear on the map and in the detection list. Select results to center or highlight them, uncheck likely false positives, and adjust the confidence slider to control what is visible and exported.

Manual Towers

Manual tower detections are corrections added after a detection run. They are different from custom search-area polygons. Select Add Towers, draw around the tower, complete the polygon, and select Save Towers.

Export And Restore

Download results exports CSV and KML. Download dataset saves the current tiles, labels, metadata, and manual additions as dataset.zip. Restore dataset reloads a previous dataset ZIP.

Treat dataset ZIPs as sensitive local data because they may contain locations, investigation context, imagery tiles, and manual corrections.

Setup And Resource Links

Settings can update provider keys, change the default provider, show performance summary, clear cache, and open Resource Links for Project Overview, User Guide, Source/licenses, Video Guides, and the research article.

The formatted source/license browser page is available at /license. Plain-text combined notices are available at /license.txt for scripts, copy/paste, or archival use.

Getting Help

Report what you were trying to do, the release version, Docker Desktop or support-directed Podman engine choice, readiness state from scripts\status.cmd -Engine docker or the same command with the explicitly selected engine, and a reviewed redacted log summary if support asks for it.

For fuller troubleshooting and support details, open the package guide at /docs/package-guide.md.

Do not share provider keys, .env, raw logs, raw screenshots, browser network traces, cached provider responses, exported datasets, named-volume contents, or sensitive AOIs unless your site has approved handling.

First-run setup is covered in the Quick Start.
