root `LICENSE.TXT` file with Creative Commons BY-NC-SA 4.0 text. That file is
not the blanket active release license for the YOLO-enabled package/image.

the project lead on October 22, 2026. Their active terms and exact identity
are in `MODEL_LICENSES.md`, with a full license copy in
`licenses/CC-BY-NC-SA-4.0.txt`. The historical file remains unchanged.

now offers the listed project-controlled code under AGPL-3.0-only while retaining
previous CC permissions and attribution. Model weights and third-party material
remain outside that grant. Do not
use the former root `LICENSE.TXT` as the current release-license source for the
Sprint 06 `agpl-yolo` release path.
