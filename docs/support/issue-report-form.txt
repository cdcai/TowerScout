TOWERSCOUT ISSUE REPORT FORM
=======================================

Last reviewed: 2026-10-25

Use this form when TowerScout setup, startup, provider setup, detection, export,
or shutdown does not work as expected. Submit the sanitized form at https://github.com/cdcai/TowerScout/issues. This is a PUBLIC issue tracker. Use only public test fixtures and sanitized diagnostics. No private reporting service is promised here.

DO NOT SEND
===========

- API keys or full `.env` files.
- Private AOI screenshots, exact private addresses, or investigation data.
- Raw logs, raw provider responses, browser network traces, tile/map URLs, or
  exported datasets. A request from a commenter does not make public posting safe.
- Provider portal screenshots that show account, billing, quota, or key details.

ADDITIONAL DIAGNOSTICS AND SECURITY REPORTS
===========================================

Do not attach raw logs or investigations here. Reproduce with a public fixture
and report the minimal sanitized error category, version, engine and device.
If sensitive information is necessary, use your established organizational
security/support channel and agree on a private transfer method first. For a
security concern, do not post exploit details, credentials or private data in
public issues. You may post a sanitized request for a private reporting contact.
GitHub private vulnerability reporting is not assumed enabled.
