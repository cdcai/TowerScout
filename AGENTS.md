# TowerScout maintenance instructions

Read `docs/maintenance.md`, `CONTRIBUTING.md`, and the relevant repository skill before implementation.
Use one primary skill and only necessary secondary checks. Work on a focused branch from accepted main.
Keep private planning, credentials, local evidence, model weights and test outputs out of commits.
The Windows package is unsigned; retain the documented process-scoped wrappers and narrow managed-endpoint claim.
Preserve named volumes, loopback binding, TLS verification, model hashes and inference settings.
Use real downloaded packages and actual model/device evidence for deployment qualification; mocked tests are source checks.
Do not import historical fork branches or tags into the receiving repository.
Public changes and publication need the applicable owner authorization. Preserve existing local work.
